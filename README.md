Alada Producciones - Sitio Web

Este proyecto es un sitio web estático/dinámico para una empresa de catering y eventos llamada Alada Producciones.

¿Qué contiene el proyecto?

- Página principal con menú de navegación e imagen destacada.
- Secciones como: Inicio, Servicios, Nosotros, Portafolio y Contacto.
- Archivos PHP para login, administración y carga de contenido.
- Archivos HTML y CSS para el diseño visual.
- Scripts en JavaScript para la interactividad.
- Recursos multimedia (audios, imágenes).
- Estructura organizada en carpetas por tipo de recurso.

Estructura de carpetas

WEB_Alada_Producciones/
 admin/ > Paneles y scripts de administración
 assets/
    css/ > Estilos (style.css)
    js/ > Scripts JavaScript
    audio/ > Sonidos usados en la interfaz
 backups/ > Archivos de respaldo
 data/ > Archivos de configuración JSON
 doc/ > Documentación adicional
 img/ > Imágenes del sitio
 pages/ > Páginas principales (index.php, test.html)
 login.php / logout.php / upload.php
 .htaccess > Configuraciones del servidor Apache

¿Cómo abrirlo?

Este sitio usa PHP, así que necesitas un servidor local como:

- XAMPP: https://www.apachefriends.org/es/index.html
- Laragon: https://laragon.org/
- WAMP: https://www.wampserver.com/

Pasos:
1.Coloca la carpeta WEB_Alada_Producciones en htdocs (o www).
2.Inicia Apache desde XAMPP o el servidor que uses.
3.Abre tu navegador y entra a:
http://localhost/WEB_Alada_Producciones/pages/test.html

¿Qué aprendí?
- Cómo organizar los archivos de un sitio web. 
- Separar correctamente HTML, CSS, JS y lógica en PHP.
